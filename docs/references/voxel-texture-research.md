# Voxel terrain texture research and implementation

## Scope

This revision corrects the miniature, noisy appearance produced by the previous
32-pixel high-frequency tiles and per-block UV rotation. Minecraft is used only
as a visual readability reference. No Minecraft artwork, resource-pack files or
protected assets are included.

The 2026-07-27 physical gameplay capture showed the concrete failure: rotated
side UVs turned the horizontal grass fringe into bright vertical strips, while
single-pixel noise made each one-metre block read like a much smaller object.
This revision addresses those two causes directly rather than changing world
geometry or camera FOV.

## Sources reviewed

- Kenney Voxel Pack: a CC0 voxel-art reference with consistent tile language and
  commercially reusable licensing: https://www.kenney.nl/assets/voxel-pack
- Godot image import guidance: nearest filtering preserves pixel edges, while
  mipmaps reduce distant grain and aliasing in 3D:
  https://docs.godotengine.org/en/3.4/tutorials/assets_pipeline/importing_images.html
- Godot material guidance: UV scaling, world-space mapping and sampling choices
  determine perceived texture scale and continuity:
  https://docs.godotengine.org/en/4.1/tutorials/3d/standard_material_3d.html

The external packs were studied for technique and licensing only. The committed
TEKNIK atlas is original project artwork generated by
`tools/generate_terrain_atlas.py`.

## Implemented texture language

- 16x16 logical artwork enlarged to 32x32 atlas cells with nearest-neighbour
  scaling. The larger logical pixels make one-metre blocks read as substantial
  world units instead of tiny patterned cubes.
- Four authored variants each for grass top, grass side, dirt, stone and sand.
- Stable orientation on every face. Grass-side fringes always remain horizontal;
  no UV rotation, transposition or quarter-tile shifting is permitted.
- Chunky two-to-four-pixel clusters instead of dense single-pixel confetti.
- One texture lookup per fragment and one shared opaque terrain material.
- Nearest-mipmap sampling to preserve block edges nearby while reducing distant
  shimmer and high-frequency noise.
- Half-texel tile insets to prevent adjacent atlas cells from bleeding into a
  face at UV boundaries.
- Biome tint remains restrained and uses the atlas average colours as references.

## Atlas layout

The atlas is 256x128 pixels, arranged as eight columns by four rows of 32x32
cells. Each cell contains 16x16 logical art scaled two times.

| Tile range | Material |
|---|---|
| 0-3 | Grass top variants |
| 4-7 | Upright grass-side variants |
| 8-11 | Dirt variants and grass underside |
| 12-15 | Stone variants |
| 16-19 | Sand variants |
| 20 | Zinc ore |
| 21 | Copper ore |
| 22 | Iron ore |
| 23 | Gold ore |
| 24-31 | Reserved neutral stone cells |

## Evidence boundary

CI can prove asset loading, shader compilation, atlas layout, native tests and
Android ARM64 packaging. It cannot prove the visual scale or frame-time result on
the Vivo T3x. Physical gameplay remains the final acceptance gate.
