# Reference Mod Capability Map

No single reference mod is treated as the primary design. The base **Create** philosophy is the central doctrine: engineering must be visible, spatial, understandable, player-built and physically expressed in the world.

These projects are references for system design only. TEKNIK uses original code, names, assets, recipes, progression and visual identity.

| Reference | What TEKNIK studies from it | TEKNIK subsystem |
|---|---|---|
| Create | Visible kinetic networks, spatial automation, readable cause and effect, contraption construction | Central engineering doctrine and kinetic foundation |
| Create Aeronautics | Large assembled craft, propulsion placement, control surfaces, walking on moving constructions | Later aircraft and moving-reference-frame research; not the primary game doctrine |
| Trains and Transit Expansion | Transit components, station-oriented transport and railway expansion | Rail transport content and logistics |
| Create Crafts & Additions | Converting rotational power into electricity and powered tools | Kinetic-electrical conversion |
| Create: New Age | Electrical generation, distribution, motors and higher-energy machinery | Electrical network and industrial progression |
| Create: Diesel Generators | Liquid fuels, engines and generator-driven mechanical power | Combustion and fuel infrastructure |
| Create: Ultimate Factory | Large production chains and factory-scale throughput | Late-game manufacturing and production planning |
| Create: Interactive | Contraptions that preserve meaningful block interaction | Interactive assembled structures |
| Create Utilities | Practical movement, access and quality-of-life engineering components | Utility engineering layer |
| Create: Power Loader | Large movable assemblies and heavy industrial manipulation | Heavy material handling and construction equipment |
| Create Dreams and Desires | Expanded component variety and alternative manufacturing paths | Content breadth and optional production routes |
| Additions | Supplemental machinery and missing connective components | Gap-filling reference only; no undefined feature is accepted without its own design |
| Create Big Cannons | Multiblock artillery construction, loading and recoil concepts | Artillery and large weapon engineering |
| Create: Alloyed Guns | Manufactured firearms tied to material and production systems | Survival weapon manufacturing |
| Create Stats & Additions | Instrumentation, measurements and engineering feedback | Telemetry, diagnostics and machine statistics |
| Create: Steam 'n' Rails | Expanded trains, bogeys, track systems and railway operations | Core rail engineering reference |
| CC: Tweaked / ComputerCraft integration | Sandboxed programmable computers, peripherals and automation control | In-world programming and telemetry control |

## Design rule

A feature is accepted only after answering four questions:

1. What player problem does it solve?
2. What visible physical process communicates how it works?
3. Which TEKNIK simulation owns it?
4. Can the target Android device support it at the required scale?

Reference mods guide understanding. They do not dictate architecture or justify copying implementation details.
